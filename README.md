### 1. SmartSpam – AI-Based Spam Classification System

An NLP and Machine Learning web application that classifies SMS messages as Spam or Ham.

**Technologies:** Python, Flask, NLTK, Scikit-learn, TF-IDF, SQLite, HTML, CSS, JavaScript.

- Text preprocessing and feature extraction.
- Multiple machine learning algorithms compared.
- Calibrated LinearSVC selected as the production model.
- Achieved 99.03% accuracy on the held-out test dataset.
